1. Future Value of a Lump Sum

Question: What will one amount today be worth after it earns interest over time?

Build checklist

  1. Label your three inputs: present value, interest rate, and number of periods.
  2. Format the present value and answer as currency; format the rate as a percentage.
  3. Use Excel's future-value financial function to calculate one ending value.
  4. Change one input at a time and explain why the answer changes.
Self-check: With a positive rate and no withdrawals, the future value must be larger than the present value.

2. Simple Interest versus Compound Interest

Question: How much of the growth is interest on the original amount, and how much is interest earned on prior interest?

Build checklist

  1. Set up present value, annual interest rate, and number of years.
  2. Calculate the ending value using compound growth.
  3. Calculate simple interest separately.
  4. Subtract to identify interest earned on interest.
Self-check: At a positive rate for more than one period, compound growth should exceed simple-interest growth.

3. Present Value

Question: What is a future amount worth today, given the rate of return and time available?

Build checklist

  1. Label future value, interest rate, number of periods, and periodic payment.
  2. Use zero for payment when the problem has no recurring cash flow.
  3. Use Excel's present-value financial function and follow the sign convention demonstrated in class.
  4. Format the result as currency, then check whether the sign is communicating a cash outflow.
Self-check: For a positive future amount and positive rate, the amount today should be smaller in magnitude than the future amount.
